# Rice Supply Chain Management System

## 📌 Project Overview
The Rice Supply Chain Management System is a web-based application developed using Python and Django. The system helps manage and monitor the flow of rice from procurement to distribution. It allows managers to track paddy purchases, rice stock, payments, and generate reports efficiently.

This system improves transparency, reduces manual errors, and streamlines the rice supply chain process.

---

## 🚀 Features
- Paddy procurement management
- Rice stock management
- Purchase and sales tracking
- Payment management
- Manager dashboard
- Search and filter functionality
- PDF report generation
- Stock and financial report tracking

## ⚙ Installation Steps

### 1. Clone the Repository
git clone https://github.com/Raghavendra-w/Rice-Supply-Chain-Management-System.git


### 2. Navigate to Project Folder
cd Rice-Supply-Chain-Management-System


### 3. Create Virtual Environment
python -m venv venv


### 4. Activate Virtual Environment
Windows:venv\Scripts\activate

### 5. Install Dependencies
pip install -r requirements.txt


### 6. Run Migrations
python manage.py migrate


### 7. Run the Development Server
python manage.py runserver


Open browser and go to:
http://127.0.0.1:8000/
